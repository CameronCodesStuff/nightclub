# Idle Nightclub

A simple browser-based idle nightclub game made with HTML, CSS, and JavaScript.

## Features

* Earn cash automatically over time
* Upgrade the Bar
* Upgrade the DJ Booth
* Upgrade the VIP Lounge
* Invite customers to the nightclub
* Increase income per second
* Customer multiplier system
* Animated nightclub crowd
* Lasers, disco lights, speakers, and other animations
* $1000 test/debug button

## How to Run
Open this [Link](https://cameroncodesstuff.github.io/nightclub/)

or

1. Download or clone the project.
2. Open `index.html` in a web browser.
3. Start earning cash and upgrading your nightclub.

No installation or external dependencies are required.

## Built With

* HTML
* CSS
* JavaScript

## How to Play

You start with $0 and earn $1 per second.

Use your money to purchase upgrades:

| Upgrade    | Starting Cost | Income Bonus |
| ---------- | ------------: | -----------: |
| Bar        |           $10 |      +$1/sec |
| DJ Booth   |           $25 |      +$2/sec |
| VIP Lounge |          $100 |      +$5/sec |

Each upgrade also adds a customer to the nightclub.

Customers increase your income multiplier by 0.1x per customer.

You can also use the Invite button to bring in a customer for 15 seconds.
